# 🌾 AgroForte 2026

Um projeto web moderno e responsivo dedicado à tecnologia, produção e sustentabilidade no agronegócio.

## 🎯 Sobre o Projeto

AgroForte 2026 é uma plataforma educacional e informativa sobre o futuro do agronegócio, apresentando:

- **Tecnologia Agrícola**: Máquinas inteligentes e agricultura de precisão
- **Sustentabilidade**: Produção responsável e eficiente
- **Crescimento**: Visualização de dados sobre produção agrícola
- **Inovação**: Soluções modernas para o campo

## ✨ Características

- ✅ Design responsivo (Mobile-first)
- ✅ Interface moderna com Tailwind CSS
- ✅ Gráficos interativos com Chart.js
- ✅ Ícones com Font Awesome
- ✅ Animações suaves
- ✅ Otimizado para SEO
- ✅ Carregamento rápido

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica
- **CSS3**: Estilos customizados
- **JavaScript**: Funcionalidades interativas
- **Tailwind CSS**: Framework CSS utilitário
- **Chart.js**: Biblioteca de gráficos
- **Font Awesome**: Ícones
- **Unsplash**: Imagens de alta qualidade

## 🚀 Como Usar

### Opção 1: Abrir Localmente
1. Clone o repositório:
```bash
git clone https://github.com/ezequiellove996-cmyk/agroforte-2026.git
```

2. Navegue até o diretório:
```bash
cd agroforte-2026
```

3. Abra o `index.html` em seu navegador (duplo clique ou arraste para o navegador)

### Opção 2: Usar com um Servidor Local
```bash
# Com Python 3
python -m http.server 8000

# Com Node.js (http-server)
npx http-server
```

Acesse: `http://localhost:8000`

### Opção 3: GitHub Pages
1. Ative GitHub Pages nas configurações do repositório
2. Selecione a branch `main`
3. Acesse `https://ezequiellove996-cmyk.github.io/agroforte-2026/`

- Desktop: Layout completo com 3 colunas
- Tablet: Layout adaptado
- Mobile: Layout em coluna única

## 🔧 Customizações Possíveis

Você pode facilmente customizar:

1. **Cores**: Altere os valores das classes Tailwind em `index.html`
2. **Imagens**: Substitua as URLs do Unsplash
3. **Dados do Gráfico**: Modifique os valores em `script.js`
4. **Conteúdo**: Edite o texto nos cards e seções
5. **Estilos**: Adicione novas regras em `styles.css`
